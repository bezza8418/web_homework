## Описание проекта
Простое веб-приложение с сервером на встроенной библиотеке Python и Bootstrap интерфейсом.

## Функциональность
- Главная страница с приветствием
- Каталог товаров
- Страница категории \"Электроника\"
- Страница контактов с формой обратной связи
- Обработка POST-запросов с выводом данных в консоль

## Запуск проекта
1. Убедитесь, что у вас установлен Python 3.6+
2. Запустите сервер:
   \`\`\`bash
   python main.py
   \`\`\`
3. Откройте браузер и перейдите по адресу:
   \`\`\`
   http://localhost:8080
   \`\`\`

## Технологии
- Python (встроенный модуль http.server)
- Bootstrap 5 (CDN)
- HTML/CSS
